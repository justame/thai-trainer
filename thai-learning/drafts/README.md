# Written lesson drafts

Keep the rolling three-day candidate horizon here as `day-NNN.json`. Every file must
remain `pending_review`, live outside the app's bundled `days/` directory, and contain
written content only. Each candidate contains exactly 20 core/related pairs, a short
two-to-six-line mini-dialogue, and pending decisions for every core pair.

Only the earliest unresolved draft is presented for decisions. Later drafts are
provisional and may change after an explicit Easy/Again progress export or direct
learner report. Draft presence is never approval. Nothing in this directory may
trigger audio generation, paid authorization, publishing, documentation updates, or
Git pushes.

`day-NNN-review.md` may mirror the earliest JSON draft as a human-readable review
table. It is presentation only; the JSON remains the structured source, and the table
must exactly match every core and related pair before it is shown.

After a draft is approved and promoted into `days/`, move its historical written JSON
and any matching review Markdown to `archive/`. Archived files are evidence only and
do not count toward the rolling three-day horizon.
