# Daily Thai written-review prompt

Prepare the next written review pack for Yaron's personalized Thai course. Use the
existing Thai-learning conversation and project history as context. Prioritize phrases
he has actually needed or is likely to reuse; do not invent personal facts.

Return exactly 20 candidate sentences spanning multiple recurring categories. Unless
the user requests a themed pack, no category may occupy more than four sentences. For
each, provide:

1. Hebrew recall prompt.
2. Natural everyday Thai, using male `ผม`/`ครับ` forms only where natural.
3. Tone-marked romanization.
4. Short literal structure in Hebrew.
5. Context, register, and ambiguity note in Hebrew.
6. One reusable Thai pattern.
7. One useful variation.

Also provide a short mini-dialogue, showing every spoken line in Hebrew and Thai. End
with a checklist that lets the user approve, edit, replace, or reject every item.

Hard boundary: this run prepares written text only. Do not create audio, configure or
call a speech service, spend money, buy credits, or infer approval. If the previous
pack is still pending review, present that pending pack instead of creating a new one.
